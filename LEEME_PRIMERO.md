# Antes de empezar

## 1. Descarga el material completo

En GitHub selecciona **Code → Download ZIP** y descomprime todo el archivo. También puedes clonar el repositorio con Git.

No copies únicamente un `.pbip`: cada proyecto necesita las carpetas `.Report` y `.SemanticModel` que están a su lado.

## 2. Parte guiada

Abre:

`proyectos/00_marea/Marea.pbip`

Si Power BI solicita credenciales para `raw.githubusercontent.com`, selecciona **Anónimo**, aplica el permiso al dominio y ejecuta **Actualizar** una vez.

## 3. Taller

Escoge un solo caso:

- `proyectos/01_ropa/Ropa.pbip`
- `proyectos/02_musica/Musica.pbip`
- `proyectos/03_logistica/Logistica.pbip`
- `proyectos/04_atencion/Atencion.pbip`

Lee primero la ficha correspondiente. Los retos tienen relaciones y calendario, pero no medidas, gráficos ni conclusiones.

## 4. Tema visual

En Power BI usa **Vista → Temas → Examinar temas** y selecciona el JSON correspondiente dentro de `temas/`.

El tema ofrece una paleta inicial. El equipo todavía debe decidir jerarquía, posición, tamaño, gráfico, títulos, anotaciones y narrativa.

## 5. Guarda tu trabajo

Guarda una copia completa de la carpeta del proyecto con el nombre del equipo. No guardes únicamente el archivo `.pbip`.
