# Temas de Power BI

Cada caso incluye una paleta inicial, pero el tema no resuelve el diseño del dashboard. El equipo todavía debe decidir jerarquía, contraste, posición, tamaño, títulos y anotaciones según su pregunta de negocio.

## Cómo importar un tema

1. Abre el proyecto correspondiente en Power BI Desktop.
2. Ve a **Vista → Temas → Examinar temas**.
3. Selecciona el JSON del sector.
4. Revisa el resultado: no uses todos los colores al mismo tiempo ni dependas únicamente del color para comunicar una diferencia.
